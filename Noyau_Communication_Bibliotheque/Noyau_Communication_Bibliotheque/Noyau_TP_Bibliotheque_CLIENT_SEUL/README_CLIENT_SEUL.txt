VERSION CLIENT SEUL - TP INF111
=================================

Cette archive contient uniquement le projet client du noyau client-serveur.

Le client permet :
- d'écrire des commandes dans la console ;
- d'envoyer ces commandes au serveur ;
- d'afficher les réponses retournées par le serveur.

Le client ne doit pas être modifié par les étudiants.

Auteur original du noyau : Professeur Moumène Toudéft
