VERSION SERVEUR SEUL - TP INF111
=================================

Cette archive contient uniquement le projet serveur du noyau client-serveur.

Le projet client n'est pas inclus dans cette archive.
Il pourra être fourni séparément aux étudiants.

À utiliser :
1. Ouvrir le projet serveur dans IntelliJ.
2. Vérifier le package gestionnaireBibliotheque.
3. Placer les classes des parties 1 et 2 dans ce package.
4. Modifier le traitement côté serveur selon les indications de l'énoncé.
